## 这里有什么

| 目录 | 放什么 |
|---|---|
| `code/` | 练习代码。学什么开什么子目录，怎么分随你 |
| `notes/` | 笔记：概念、踩坑、面试题 |
| `projects/` | 做出来的东西，一个项目一个目录 |
| `misc/` | 不知道放哪的，全扔这 |

时间记录只有一处：[daily.md](daily.md)

## 一条规则

> **不确定放哪 → 扔 `misc/`。**

目录是给你省事的，不是给你添事的。想不清就扔 misc，回头再整理。
比「纠结放哪，最后干脆不写」好一万倍。
