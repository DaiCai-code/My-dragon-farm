## 3.1. 大模型节点

作用: 该节点可以结合大模型推理, 主打的可以处理自然语言, 甚至可以配置必要的模型插件完成一些推理性的处理任务,或者数学计算等

### 3.1.1 设置大模型节点

保证我们创建的大模型节点只有一个，选择要使用的大模型。此节点的输出内容质量很大程度上受模型能力的影响，建议根据实际业务场景选择模型。可选的模型范围取决于当前的账号类型，个人免费版或个人进阶版用户可以使用默认的几类模型，且存在对话数量限制，团队版或企业版套餐用户可以使用火山引擎方舟平台的模型。

额外扩展：

初学者可能对多条件判断不是很理解，为了让大家更好的掌握这个知识点

请阅读以下内容：

在数学中，如果我们要表示一个未知数x在1~10这个范围之内。

我们会这么写：

> 1 ≤ x ≤ 10

但是，在程序当中，这种表达式是无法连续写的，我们只能把他们拆成两个表达式：

> 1 ≤ x   和   x ≤ 10

现在，要同时满足这两个表达式，才叫做x在1~10之间

所以，我们需要用而且，把他们连在一起。最终写成：

> 1 ≤ x   而且   x ≤ 10

那么，在代码当中用于连接多个条件的符号叫做逻辑运算符，常见的有两个：

- 而且，写作：&&
- 或者，写作：||

## 3.2 工作流中的其他常用节点（续 2）

意图识别（Intent Recognition）指的是让智能体理解用户通过自然语言表达的意图或目的。意图识别是智能助手的典型能力。

例如：用户输入"我想看今天的 AI 新闻"，其中"查看新闻"为用户意图，也就是用户希望智能体执行的操作。

扣子工作流支持意图识别节点对用户意图进行归类，使工作流运行更加高效。

意图识别节点可用于以下场景：

- 客户服务：识别用户问题的类型，并转交各类知识库处理，对于知识库中未匹配的问题，转交人工客服处理。
- 医疗咨询：对用户咨询的医学问题进行归类，非医学问题的咨询则拒绝回复。
- 综合类智能体：对于功能多样的智能体，可以先由意图识别节点对用户咨询进行初步分类，转交各个 Agent 分支处理。

#### 3.2.3.1 输入节点

在比较复杂的工作流场景中，某些节点的执行往往需要额外的用户输入。如果上游节点中没有获取到这些信息，你可以添加一个输入节点来主动收集信息。工作流执行到输入节点时会暂时中断，直到此节点收集到必要的用户输入。实际上，开始节点就是特殊的输入节点。

#### 3.2.3.2 输出节点：

通常情况下，工作流会在执行完毕后通过结束节点输出最终的执行结果。当工作流处理流程较长、运行时间较久时，开发者可以在工作流中添加输出节点，临时输出一段消息，避免用户等待时间过长、放弃对话。

例如：提示用户任务正在执行中，建议用户耐心等待，相当于就是一个提示语句。
