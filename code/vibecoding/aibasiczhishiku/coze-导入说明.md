# Coze 知识库导入说明

## 一、上传这些文件

打开扣子 → 资源库 → 知识库 → 创建知识库 → 类型选 **文本格式**，然后把下面这个目录里的 **36 个 `.md` 文件全选拖进去**：

```
coze-导入包/
```

本说明文件放在包外，不用上传。

已按「159620 字 / 212 块」预处理好，单块最长 1745 字，可直接配合下面的分段参数使用。

## 二、分段参数怎么填

| 配置项 | 填什么 | 为什么 |
| --- | --- | --- |
| 知识库类型 | 文本格式 | Coze 的图片/表格类型不适用这种课件 |
| 分段方式 | **自定义分段** | 自动分段会按固定长度硬切，把一个小节切断 |
| 分段标识符 | `\n## `（换行+两个井号+空格） | 每个二级标题一块，正好是本课件的知识点边界 |
| 最大分段长度 | **2000** | 现有分块都小于 1745，填 2000 保证不会被二次硬切 |
| 分段重叠 | **0** | 块之间已有标题隔离，重叠只会在检索时重复命中 |
| 文本预处理 | 勾选「替换连续空格、换行符、制表符」 | 其余两项不用勾，正文无长链接 |

> 如果界面只让用「自动分段与清洗」：最大分段长度填 **800**、重叠 **100**。能用自定义就尽量用自定义，检索命中率差别比较明显。

## 三、包里做了什么处理

- **所有配图已剔除**。Coze 只索引文字，`![图](assets/…)` 只会变成噪声；原图仍保留在主知识库各章的 `assets/` 目录。
- **已删除**：飞书原文链接行、白板/画板占位、`0 个结果` 这类渲染残留、章内跳转链接（上传后必然失效）。
- **已保留**：标题层级、有序/无序列表、表格、代码块——课程里最需要被精确检索的就是这些。
- 每个文件开头一行写明「课程 / 章节 / 本节」，即使被切碎，第一块也带上下文。
- 与前章重复的「学习目标」已并入各章导读，没有重复入库。
- 超长小节按自然段切成「（续 2）（续 3）」，保证每块语义完整、不被平台从句子中间切断。
- 个别超长代码块（整段 JSON 输出、长录音稿）同样按长度切分，围栏保持完整；需要完整原文时回主知识库对应章节查看。

## 四、挂到智能体之后

1. 智能体编排页 → 知识库 → 添加刚建的知识库 → 打开「搜索知识库」（或允许自动调用）。
2. 召回条数 Top K 建议 **3~5**，课程问答不需要太多。
3. 提问带上章节锚点命中更准，例如：「第4章工作流里，大模型节点怎么设置输出格式」。
4. 课件更新后重新生成本包，文件名保持不变，在知识库里重新上传即可覆盖旧版本。
