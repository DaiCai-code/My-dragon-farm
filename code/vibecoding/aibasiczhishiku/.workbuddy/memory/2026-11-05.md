## 飞书课程知识库转 Markdown（AI 智能应用基础班，第1-6章）

- 源：`https://baxsu7o100e.feishu.cn/wiki/VBkIw2dYJiaieKkpA4GcZwoOnWv`（公开分享的知识库，匿名可读，无需用户登录态）
- 产物：当前目录下的分层知识库 —— `README.md`、`00-知识库导航.md`、`第01~06章-*/`（每章 `00-本章导读.md` + 分节 md + `assets/` 配图），共 40 个 md、32 个分节、495 张图，约 95MB。
- 关键技术结论（可复用）：
  1. 飞书 wiki 页面是 SPA，直接 curl 会拿到登录门页；但公开分享页用**无头 Edge 渲染**即可匿名访问，正文通过 WebSocket 下发，抓不到普通 HTTP 接口。
  2. `data-block-id` 是文档内递增序号：抓取后校验 1..N 连续即可确认无漏块（本次 6 章全部 0 缺失）。
  3. 飞书 docx 长文档**虚拟列表**会回收已滚出视口的块，必须边滚动边增量采集（按 `data-block-id` 去重、按首次出现顺序排序）。
  4. 表格渲染为「sticky 表头 table + 正文 table」两个 `<table>`，需按 `tr[data-index]` 合并去重，否则只剩表头。
  5. 图片 `src` 多为 `blob:`；用 `https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/preview/<image-token>/?preview_type=16` 配合浏览器访客 Cookie 可拿到原图。
  6. 容器块（quote_container / callout / grid）的 `innerText` 已包含子块文本，直接输出会与子块重复，应只保留子块。
- 工具链：Edge `--headless=new --remote-debugging-port=9333` + Node 22 内置 WebSocket 手写 CDP 客户端（无需 puppeteer）；转换用 Python + bs4/lxml。
- 注意：文件名清洗需把 ASCII 括号转全角，否则 markdown 链接解析会被截断。

## 追加：生成 Coze（扣子）知识库导入包

- 派生目录 `coze-导入包/`：36 个 md（5 章导读 + 31 节 + 第5章学习目标），212 个知识块，约 16 万字，458KB。
- 清洗规则：删图片引用（Coze 只索引文字）、飞书原文链接行、白板占位、`0 个结果`、章内跳转链接；保留标题/列表/表格/代码块。
- 分段约定：每块以 `## ` 开头，块长 300~1745 字（上限 1400 自动切）；超长小节切为「（续 N）」，长代码块按 `\n` 转义切分并保持 ``` 围栏成对。
- Coze 参数：文本格式 / 自定义分段 / 分隔符 `\n## ` / 最大长度 2000 / 重叠 0 / 勾选替换连续空格换行。
- 坑：`00-本章导读.md` 会被 `\d{2}-` 正则误当成普通小节，需排除；代码块切分必须单独处理，否则围栏断裂。
