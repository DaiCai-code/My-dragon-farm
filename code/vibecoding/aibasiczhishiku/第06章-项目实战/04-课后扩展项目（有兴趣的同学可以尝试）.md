## 家庭医生产品需求文档

## 4. 项目概述

构建基于AI的家庭医生智能工作流，通过动态用户画像串联健康评估、运动饮食干预、体检分析及用药安全等核心场景，为用户提供全周期、个性化的智慧健康管理闭环服务。

## 5. 核心功能模块

### 5.1 动态用户画像（全局基石）

- 触发机制：用户首次进入工作流时自动触发信息采集。
- 数据维度：包含基础信息、既往病史、家族史、过敏史、当前用药清单等。
- 动态更新：在后续健身、饮食、体检等交互中，自动捕获新数据并实时修改用户画像，确保所有服务基于最新状态。

### 5.2 私人医生（智能问诊与分诊）

- AI预问诊：用户咨询身体不舒服了，结合知识库和大模型，进行初步分诊与轻重缓急评估。
- 画像联动：问诊过程中实时调用用户画像，生成个性化健康指导。

### 5.3 用药安全与过敏记录管理

- 用药管理：如果用户身体不舒服，正在用药，实时更新用药清单
- 过敏管理：如果用户用药过敏，实时更新过敏史
- 交互拦截：用户咨询用药，系统强制校验用户画像中的过敏史与当前用药，若存在冲突或禁忌，立即提醒用户。

### 5.4 健身与体重管理

- 个性化规划：基于用户画像（含基础疾病、体能状况）生成专属健身计划与减肥计划。

### 5.5 饮食指导与营养分析

- 画像联动：结合用户画像（如高血压、糖尿病等）提供定制化饮食禁忌与营养补充建议。

### 5.6 体检报告智能分析

- 循环解析引擎：利用AI循环机制，按系统（肝胆、内科、外科、心血管等）逐一提取并分析异常指标。
- 趋势与干预：对比历史体检数据，输出异常趋势图，并给出针对性的复查建议或生活方式干预方案。

## 6. 具体模块如下：

- 创建用户信息表：包含个人基础信息、既往病史、家族病史、过敏史、当前用药清单、当前饮食习惯、健身情况等数据，该字段需要结合下面的业务而定。
- 创建知识库：收集一些基本的病症信息。
- 初始工作流：用户第一次进入 -> 触发画像采集 -> 建立健康档案
- 咨询工作流：发起咨询 -> 调取画像 -> 安全校验（过敏/用药） -> 输出建议 -> 更新档案。
- 健身工作流：调取画像 -> 生成健身/饮食计划  -> 动态调整计划。
- 分析工作流：上传体检报告 -> 循环解析各系统指标 -> 结合画像输出综合评估 -> 归档并推送干预建议。
