## 学习路径建议

1. **第1章** 打底：搞清「智能应用 = 传统模块 + 智能模块」，理解模型、Token 计费、vibecoding。
2. **第2章** 最关键的前置：提示词五大原则与模板，后面所有章节都依赖它。
3. **第3章** 上手 Coze：不写代码搭智能体，理解人设、技能、插件、知识库。
4. **第4章** 工作流：节点编排是把智能体做成"可用产品"的核心。
5. **第5章** 进阶：数据库、多模态、循环结构，解决复杂业务闭环。
6. **第6章** 综合实战：简历评估 / 面试录音分析 / 面试题生成三个项目串起全部知识点。

## 导入 Coze（扣子）知识库

需要把课程喂给智能体时，用 `coze-导入包/` 这个派生目录，不要直接传上面的主目录。

- **36 个 `.md` 文件、212 个知识块、约 16 万字**，已剔除图片引用与失效链接，保留标题/列表/表格/代码块。
- 上传入口：扣子 → 资源库 → 知识库 → 新建（类型选「文本格式」）→ 把 `coze-导入包/` 里的文件全选拖入。
- 分段建议：方式选「自定义分段」，分隔符 `\n## `，最大长度 2000，重叠 0，勾选「替换连续空格/换行/制表符」。
- 详细参数、文件清单与注意事项见 **`coze-导入说明.md`**。

## 使用说明

- 每章 `00-本章导读.md` 是入口，含学习目标与本节链接。
- 每节文件自成单元，标题从 `#` 起，便于单独阅读或切块入库。
- 配图路径为相对路径 `assets/fig-*.png`，移动目录时整章一起移动即可。
- 引用块（`>`）对应原文的「备注 / 温馨提示」，属于讲师补充说明。
