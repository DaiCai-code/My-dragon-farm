# 用本知识库做试卷 · 操作指南

> 知识库资产：`coze-导入包/`（36 个 md，纯文本、已预分段，适合检索）
> 主知识库：`第01章` ~ `第06章`（含 495 张配图，适合人工核对）

---

## 一、两条路径，选一条

| | 路径 A：本地直接做 | 路径 B：搭成 Coze 智能体 |
|---|---|---|
| 适合 | 一次性做掉这份试卷 | 以后反复出题、答疑、批量测评 |
| 需要 | 把试卷 md 放进本目录 | 上传知识库 + 建 Bot |
| 速度 | 立刻 | 首次约 15 分钟，之后零成本 |
| 准确度 | 高（逐题检索原文） | 高（检索命中后作答） |

---

## 二、路径 A：把试卷交给我

1. 把试卷 md 文件放到本目录（例如 `试卷.md`），或直接把内容粘贴到对话里。
2. 我会执行下面这套流程，产出 `试卷-答案卷.md`：

```
读题 → 拆出考点关键词 → 在 36 个分节里检索原文
     → 命中则引用原文作答 → 未命中标注「知识库未覆盖」
     → 逐题输出：答案 / 解析 / 出处（第N章-小节名）
```

3. 输出格式固定为：

```markdown
### 1. 【单选题】题干……
**答案**：B
**解析**：……（依据原文表述）
**出处**：第4章-03-工作流常见的节点 → 「大模型节点」

### 2. 【简答题】题干……
**答案**：
（分点作答，术语与课件保持一致）
**出处**：第5章-05-循环结构
```

**关键约定**：凡是知识库中没有依据的题，我不会硬编，而是单独列在末尾的「待确认清单」里，由你判断是否需要补充资料。这是保证试卷可信的前提。

---

## 三、路径 B：在 Coze 里搭一个「课程助教」

### 步骤 1 · 建知识库
- 扣子 → 资源库 → 知识库 → 新建 → 类型选 **文本格式**
- 把 `coze-导入包/` 下 36 个 md 全部拖进去
- 分段设置（**别用默认值**）：
  - 方式：自定义分段
  - 分隔符：`\n## `
  - 最大长度：`2000`，重叠 `0`
  - 预处理：只勾「替换连续空格、换行符、制表符」

包里的文件已按这个规则预切好（212 块，最长 1745 字），不会被二次硬切。

### 步骤 2 · 建 Bot，贴入系统提示词

把下面整段复制到 Bot 的「人设与回复逻辑」：

```text
# 角色
你是《AI智能应用开发》课程的助教，负责依据课程知识库批改和作答试卷。

# 铁律
1. 所有答案必须能在知识库中找到依据，禁止凭常识或训练记忆编造。
2. 每道题作答后，必须标注出处：第N章-小节名。
3. 知识库中查不到依据的题，答案写「【知识库未覆盖】」，不要猜测。
4. 术语、参数名、界面名称必须与课件原文完全一致（例如「大模型节点」「循环体」「变量节点」），不得改写。

# 作答流程
1. 先提取题干中的考点关键词（平台名/节点名/概念名）。
2. 用关键词检索知识库，取最相关的 1-2 段原文。
3. 依据原文作答；原文与题目冲突时以原文为准，并注明冲突点。

# 输出格式
按题号逐题输出，每题固定三段：

### {题号}. 【{题型}】{题干摘要}
**答案**：{答案}
**解析**：{1-3 句，说明依据原文的哪句话}
**出处**：{第N章-小节名}

全部题目结束后，输出：
## 待确认清单
- 列出所有「知识库未覆盖」的题号及原因

# 题型处理
- 单选/多选/判断：只给选项字母 + 一句话理由
- 填空：给原词，不改写同义词
- 简答：分点作答，每点一个短句，不超过 5 点
- 实操/项目题：按课件中的操作步骤顺序作答，标明关键节点与参数
```

### 步骤 3 · 提问方式
把试卷分段发（一次 10 题以内），开头写一句：

```
请依据知识库作答以下题目，严格按输出格式：
（粘贴题目）
```

一次性贴几十题容易触发上下文截断，分批更稳。

## 四、做之前值得知道的三件事

1. **第 5 章缺「本章导读」在包外**：`第5章-01-学习目标.md` 就是第 5 章的入口，别以为漏了。
2. **超长代码块被切分**：第 6 章两个项目实战里的长 JSON / 录音稿，包内按长度切成了多段，围栏是完整的，但单条内容可能断开——涉及这类题回主知识库对应章节看原文。
3. **附录无正文**：原飞书文档的附录节点只有标题，试卷若考到附录内容，属知识库未覆盖。

## 五、如果试卷题型偏实操

实操题（如「搭建一个简历评估工作流」）光靠检索不够，需要看截图。这时用主知识库：

- `第06章-项目实战/01-项目一：简历评估.md` 等文件里带 `assets/` 配图
- 我可以直接读图核对界面细节，再作答

告诉我试卷里有几道实操题，我把对应的图调出来一起看。
