# 学习目标：

> 来自《Coze的进阶使用》· [原文](https://baxsu7o100e.feishu.cn/wiki/KzUPwnjIsinaN7kB2JRcWuhrnZ7)

1. 理解数据库与数据表的基本概念
2. 能区分数据库与知识库的适用场景
3. 掌握在Coze中创建扣子数据库、设计表结构及批量导入数据的方法
4. 能够使用工作流中的数据库节点（增、删、改、查）实现数据的持久化操作
5. 学会利用大模型节点进行实体提取（如人名、工号），为数据库操作提供参数
6. 掌握多模态处理能力：文生图、图像画质提升、语音识别（ASR）、语音合成（TTS）及视频生成
7. 理解循环结构的作用，能够配置循环节点（数组循环、指定次数循环）实现任务批量处理
8. 能够将循环结构与数据库、大模型节点结合，完成批量文案生成等复杂业务
9. 学会通过循环拆分大任务，降低单次模型处理压力，提升生成内容质量
10. 能够综合运用数据库、循环、多模态等技能，完成“学生管理系统”项目实战（批量增删改查、条件筛选、检讨书生成）
11. 掌握项目开发中的成本控制意识，能够分析节点积分消耗并优化工作流设计
