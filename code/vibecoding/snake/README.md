# 霓虹蛇行 / NEON SERPENT

一个赛博朋克风格的贪吃蛇小游戏。透视网格地平线、霓虹蛇身、CRT 扫描线与噪点，
全部音效由 WebAudio 实时合成 —— **零依赖、零构建、零音频文件**，双击 `index.html` 就能玩。

断网也能正常游玩：字体自动降级到系统等宽字体，音效与画面完全不受影响。

## 运行

直接双击 `index.html`，用浏览器打开即可（推荐 Chrome / Edge / Firefox 最新版）。

如果想用本地服务器跑（部分浏览器对 `file://` 限制较多）：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000/
```

## 玩法

- 吃掉品红色的**数据点**，蛇身变长、分数上涨
- 撞上红色的**边界护栏**或**自己的身体**，这一局就结束了
- 连着快速吃掉数据点会触发**连击**，最高 ×5，分数翻倍
- 把整个棋盘填满则判定 **PERFECT HACK**，完美通关

## 操作

| 操作 | 键盘 | 手机 |
| --- | --- | --- |
| 转向 | `↑` `↓` `←` `→` / `W` `A` `S` `D` | 滑动 |
| 开始 | `Enter` / `空格` | 轻点屏幕 |
| 暂停 / 继续 | `P` / `Esc` | — |
| 静音开关 | `M` | 点右上角按钮 |
| 重开 | `Enter` / `R` | 点结算面板按钮 |

对局进行中按 `R` 不会有反应 —— 防止误触把当前这局直接扔掉。

## 目录结构

```
snake/
├── index.html          # 页面骨架：双画布 + HUD + 开始/暂停/结算界面 + 氛围层
├── style.css           # 赛博朋克视觉主体：色阶变量、HUD、界面、氛围层、响应式
├── js/
│   ├── constants.js    # 全部可调参数、配色、按键映射、工具函数
│   ├── core.js         # 纯游戏逻辑：方向队列、碰撞、进食、计分、插值坐标
│   ├── render.js       # 双画布渲染：网格地平线、蛇、数据点、粒子、飘字、震屏
│   ├── audio.js        # WebAudio 合成：tone / noise / arp / 背景 drone
│   └── game.js         # 状态机、固定步长主循环、输入分发、HUD 更新
├── tests/
│   └── run.js          # 纯逻辑自测（Node 内置 test 模块，零依赖）
└── README.md
```

`js/core.js` 完全不碰 DOM，所以游戏规则可以脱离浏览器单独测试。

## 自测

游戏的核心规则（转向防自杀、碰撞、进食、连击、速度曲线）都有单测覆盖：

```bash
node --test tests/run.js
```

## 调参

手感相关的数值全部集中在 `js/constants.js` 的 `CONFIG` 里，改完保存刷新即可：

| 参数 | 含义 |
| --- | --- |
| `GRID.cols` / `GRID.rows` | 棋盘格子数 |
| `SPEED.startStepMs` | 初始每走一格多少毫秒 |
| `SPEED.minStepMs` | 最快每格多少毫秒 |
| `SPEED.curveK` / `SPEED.tierEvery` | 速度曲线：每吃几个数据点快一点、每次快多少 |
| `SCORE.perFood` | 每个数据点的基础分 |
| `SCORE.maxCombo` | 连击倍率上限 |
| `SCORE.comboWindowMs` | 两次进食间隔小于多少毫秒算续上连击 |
| `SNAKE.initLength` | 开局蛇身长度 |
| `QUEUE_MAX` | 方向缓冲队列长度 |

配色在 `js/constants.js` 的 `PALETTE` 里，与 `style.css` 的 `:root` 变量一一对应。

## 技术说明

- **纯原生**：没有框架、没有打包器、没有 `package.json`，脚本按顺序用 `<script src>` 引入
- **两套画布**：`#bg` 画透视网格地平线（静态部分预渲染到离屏画布再平铺），`#stage` 画蛇、数据点和粒子
- **逻辑与渲染分离**：蛇是「格坐标数组」，渲染时在上一位置和当前位置之间做插值，所以蛇头在两格之间是平滑滑过去的
- **方向缓冲队列**：转向按键先进队列，每走一格取一个；180° 掉头会被直接丢弃，玩家快速连按两次也不会自己撞死
- **音效全合成**：`tone()` / `noise()` / `arp()` 三个基础音源，加两个失谐锯齿波做的背景低鸣
- **移动端**：滑动转向、轻点开始，系统开启「减少动态效果」时所有装饰动画自动降级
