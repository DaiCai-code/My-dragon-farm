# 围棋启蒙

一款面向围棋初学者的中文教学小游戏。从数气、提子开始，边看规则、边做练习，再和简易 AI 下完一盘棋。

纯前端实现，零依赖、零构建：**双击 `index.html` 就能玩**。

## 功能

- **人机对战**：玩家执黑先行，AI 执白。支持 9 路与 13 路棋盘，三档难度（入门 / 初级 / 进阶）。
- **实时教学提示**：悬停交叉点即可看到气数、可提子数、是否会自打吃；悬停已有棋子会标出整块棋的气。
- **吃子与围地提示**：自动标出被打吃的棋串；打开“显示地域”后按归属给空区着色。
- **推荐落点**：点击“提示”，棋盘上会用 1/2/3 标出推荐点，侧栏给出理由。
- **规则小课堂**：5 节图文课，覆盖气与提子、禁着点、打劫、围地数子、常用术语；带可交互的“试一试”。
- **新手关卡**：6 个单目标关卡，依次练习数气、提子、逃出打吃、禁着点、打劫、围地，通关进度自动保存。
- **对局操作**：悔棋、停一手、认输、重新开始；触摸设备采用二次确认，减少误触。

## 开始使用

直接用浏览器打开：

```text
weiqi/index.html
```

无需安装依赖，也无需启动服务器。若浏览器对本地文件有限制，可在项目目录运行任意静态文件服务器，例如：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 怎么玩

1. 先点“规则小课堂”浏览 5 节课，遇到“试一试”可以亲手落子。
2. 切换到“新手关卡”，按顺序完成 6 个目标；点击棋盘交叉点落子。
3. 进入“对局”和 AI 下棋。拿不准时把鼠标移到交叉点上，或点“提示”。

### 操作方式

| 操作 | 鼠标 / 触摸 | 键盘 |
|---|---|---|
| 落子 | 点击交叉点 | 方向键移动光标，`Enter` 落子 |
| 取消预览 | 点“取消” | `Esc` |
| 悔棋 | “悔棋”按钮 | `U` |
| 停一手 | “停一手”按钮 | `P` |
| 推荐落点 | “提示”按钮 | `H` |

触摸设备第一次点按只显示预览和确认条，再点同一点或“确认落子”才会真正落子。

### 学习提示

- 青色小圆点是棋串的气；红色光晕表示这块棋被打吃（只剩一口气）。
- 半透明棋子是落子预览。预览标签中的“会被打吃”表示这一手落下去后自己只剩一口气。
- 棋盘下方会显示当前手数、棋盘规格和贴目；侧栏显示双方提子数与 AI 状态。
- “教学提示”关闭后，悬停提示与推荐按钮都会停用，可在顶栏重新打开。

## 规则说明

本项目实现基础围棋规则：

- 棋子上下左右相邻同色即连成一块，共享气。
- 一块棋没有气时被提掉；落子后自己无气且不能提对方棋子，属于禁着点。
- 采用简化打劫规则：提一子成劫后，对方不能立刻提回；任意一方在别处落子（或停一手）后解除。
- 双方连续停一手，或一方认输，对局结束。

终局采用**中国规则数子**：

- 黑棋总分 = 盘面黑子 + 黑棋围空。
- 白棋总分 = 盘面白子 + 白棋围空 + 贴目。
- 9 路贴 6.5 目，13 路贴 7.5 目。
- 空区若同时接触黑白双方，视为单官，不计入任何一方。

**简化约定**：终局不会自动判定死活，盘面上的棋子默认都算活棋。请在连续停一手前，把明显的死子提掉，否则结算会出现偏差。本教学版也不包含让子、超级劫、19 路棋盘与 SGF 导入导出。

## 自测

打开下面的地址可在页面中运行规则自测（共 22 项）：

```text
index.html?selftest=1
```

自测覆盖气数、提子、禁着点、打劫、悔棋、连续停一手数子、六个关卡目标、真眼、打吃扫描与 AI 合法性等。页面会列出每一项的通过 / 失败情况。

## 目录结构

```text
weiqi/
├─ index.html          页面骨架与脚本加载顺序
├─ style.css           全部样式与响应式布局
├─ README.md
└─ src/
   ├─ constants.js     颜色、文案、坐标与通用配置
   ├─ rules.js         棋串、气、提子、禁着点、打劫、落子与悔棋
   ├─ scoring.js       地域归属、中国规则数子
   ├─ ai.js            候选点评分、三档难度与推荐
   ├─ lessons.js       5 节规则小课堂数据
   ├─ levels.js        6 个新手关卡与目标判定
   ├─ boardview.js     Canvas 棋盘绘制与命中检测
   ├─ ui.js            状态栏、侧栏、提示、弹窗、课堂与关卡面板
   ├─ game.js          对局流程、AI 调度、悔棋与终局
   ├─ app.js           模式切换、输入分发与按钮事件
   ├─ main.js          启动入口
   └─ selftest.js      页面内规则自测
```

## 浏览器支持

推荐使用较新的 Chrome、Edge、Firefox 或 Safari。页面使用 Canvas 2D、`ResizeObserver`、`PointerEvent` 与 `localStorage`；隐私模式下若本地存储不可用，关卡进度会退化为仅当前页面有效。

不依赖网络、CDN、外部字体或后端服务，断网也能正常游玩。
