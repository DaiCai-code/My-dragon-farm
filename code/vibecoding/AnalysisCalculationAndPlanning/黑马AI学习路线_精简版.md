# 第二部分 · 学习思路

## 2.1 一句话

> **用 6 周时间，顺着黑马自己的课程阶梯往上一路走完；Python 基础全部快进，把时间全砸在 LangChain / RAG / LangGraph 上。**

## 2.2 最重要的一条心法：把"额外学习"变成"课前预习"

**你正在上的班，和 B 站上这些公开课，是同一个机构的同一套教材体系。**

这意味着你在 B 站学的东西**不是额外负担，而是"提前学一遍课上的内容"**。所以：

- 你现在在阶段1（前端基础，空转）→ 正好用来把 **Python + Linux** 过完
- 阶段3（RAG智能体开发，约12月）开课时 → 你**已经看过一遍了**，课堂上就是在复习和深化
- 阶段6（AgentCenter，约1月）→ 你已经看完 LangGraph 了

> **同样6周时间，别人是"多学一套"，你是"预习了一遍"。效率差在这里。**

# 第四部分 · 必须动手的三件事（视频替代不了）

看视频只解决"懂"，这三件事解决"会"：

## 4.1 用 `requests` 手写一次 LLM 调用（半天，第1周内完成）

**别用 LangChain，就用 `requests`。**

做完你会永久性理解：
- 所谓"大模型开发"，本质是**构造一个 JSON 数组发 HTTP 请求**
- `messages` 里 system / user / assistant 角色怎么工作
- **后面所有框架都只是在这上面加了一层编排**

具体做法：
1. 申请一个 LLM API Key
2. `pip install requests`
3. 手写 `messages` 数组
4. 发 POST，打印原始 JSON 响应
5. 再改成流式，看逐字输出

## 4.2 手写最小 RAG（约1周，第4周）

**目标：不用 LangChain，自己实现一遍。**

1. 读一个文档
2. 切成块 —— **自己试两种切法，看检索结果有什么不同**
3. 调 embedding 接口拿向量
4. **用 numpy 算余弦相似度**，取 top-k
5. 把检索结果拼进 prompt，让模型回答

**做完这一步，你在班里就是"知道原理的人"。** 面试问"切分策略怎么定的"你答得上来。

## 4.3 跑出一个评测数字（第5–6周）

学完 LangSmith 那段之后，**立刻自己动手**：

- 建 20–50 条测试集（问题 + 期望结果）
- 跑出一个**成功率数字**
- 失败 case 归成 3 类

**这是你简历上唯一能压过别人学校背景的东西。**

做完就能这么写：

> ❌「熟悉 RAG 与 Agent 开发」
> ✅「Agent 工具调用成功率 62% → 89%，失败 case 归因为三类：参数解析错误 / 工具选择错误 / 上下文超限」

# 第七部分 · 学习方法纪律

## 三条铁律

1. **别收藏，别囤课。** 看一个知识点，就写一篇 ≤500 字笔记 + 跑一段代码。**说不出、跑不起来＝没学。**
2. **视频只用来建立概念，不用来替代动手。**
3. **每门课从第1集顺序看，靠倍速控制节奏，不靠跳集。**

## 一条心法

> **每学完一个概念，产出一篇 ≤500 字的笔记 + 一段能跑的代码。**

这不只是学习方法——**公开的技术产出本身就是你命里最缺的那个"印"**。现在开始积累，比入职后再补省力得多。
