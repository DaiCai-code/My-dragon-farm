# 问天 · 八字命理排盘

纯前端、无后端、完全离线的传统八字排盘工具。双击 `index.html` 即可使用，不需要装任何东西，也不联网。

> 内容仅供传统文化研究与娱乐参考，不构成任何医疗、投资、法律、婚育建议。

---

## 一、怎么用

1. 双击 `index.html`（推荐 Chrome / Edge）。
2. 左栏填生辰：
   - **历法**：公历或农历，农历自动识别闰月（有闰月时才会出现「闰 X 月」勾选项）
   - **日期**：年月必填，日必选
   - **时辰**：选填。不填时按午时（12:00）估算，时柱会打上「时辰未详」标记
   - **性别**：决定大运顺排还是逆排
   - **出生地**：选填。勾选「启用真太阳时修正」且选了城市后才会参与计算
   - **精确时刻**（高级选项）：选填「时:分」。填了按此刻精算起运与真太阳时，时辰下拉会自动跟着跳；留空则取所选项时辰的中点（辰时按 08:00）
3. 点「起局排盘」。
4. 排完点「存为档案」，之后打开页面会自动回填并重新出盘。

出盘后往下是解读部分，共十张卡：总览、四柱、用神、五行、大运、早年复盘、近十年、大运详解（十步，默认只展开当前一步）、六维专题、关键时间点、趋吉避凶。

- 顶部有**吸顶目录条**，点哪一项就跳到对应卡片，横向可滑
- 每个判断下方的「依据 / 本步运的依据」默认收起，点开可看推导过程（哪一行、由多少变成多少）
- 卡片头右侧的「打印 / 存为 PDF」会把正文展开后调起浏览器打印，在打印对话框里选「另存为 PDF」即可

档案存在浏览器 `localStorage`（键 `wentian_archives_v1`），最多 50 份，超出时自动丢弃最旧的一份。清除浏览器数据即全部消失——**没有任何备份，也没有上传**。

## 二、算法口径

### 2.1 四柱

由 [lunar-javascript](https://github.com/6tail/lunar-javascript) 1.7.7 计算：

- 年柱以**立春**为界，不是正月初一
- 月柱由**节气**定，不是农历月份
- 日柱按当地钟表日期（经真太阳时修正后）
- 时柱按十二时辰；晚子时（23:00–23:59）默认算**次日**，可在高级选项里改成算当日

### 2.2 五行力量

```
天干权重：年 1.0 / 月 1.2 / 时 1.0   （日干是基准，不参与计分）
地支权重：年 1.0 / 月 2.5 / 日 1.5 / 时 1.0
藏干权重：单藏干 1.0；双藏干 0.7 + 0.3；三藏干 0.6 + 0.3 + 0.1
月令系数：当令 ×1.5 / 相 ×1.2 / 休 ×1.0 / 囚 ×0.8 / 死 ×0.6
```

力量 = Σ(天干权重 + 地支权重 × 藏干权重) × 月令系数。

这套权重是通行的近似口径，用于比较五行轻重，**不做格局成败判断**。

### 2.3 旺衰

```
帮身 = 比劫（同我）+ 印（生我）
耗身 = 食伤（我生）+ 财（我克）+ 官杀（克我）
强弱指数 = 帮身 ÷ (帮身 + 耗身)
```

| 指数 | 判定 |
|---|---|
| ≥ 0.62 | 身旺 |
| ≥ 0.53 | 偏旺 |
| > 0.47 | 中和 |
| > 0.38 | 偏弱 |
| 其余 | 身弱 |

指数 < 0.20 且天干无印比透出 → 标注「疑似从弱」；> 0.88 → 标注「疑似专旺」。这两种特殊格局在命理界有分歧，本站**只提示不硬断**，仍按常规扶抑口径排定。

### 2.4 用神

六步，顺序不可调换（否则会出现同一五行既是喜又是忌）：

1. **调候**：亥子丑月而火 < 2.0 → 火星优先入用；巳午未月而水 < 2.0 → 水同理
2. **扶抑**：身强取官杀 / 财 / 食伤中最有力的一位；身弱取印 / 比劫；中和取两强行的通关之神
3. 扶抑主用神**只取一位**，避免两个用神互相克伐
4. **忌神定稿**（必须先于喜神）：身强忌印比，身弱忌财官食伤；力量 < 0.6 的降为闲神
5. **喜神** = 生用神者，排除已占用的五行
6. **仇神** = 生忌神者；剩下的是**闲神**

用 / 喜 / 忌 / 仇 / 闲 五类严格互斥，界面上每一类的判定依据都会写明具体力量数值，可自行核对。

### 2.5 起运

阳年男命、阴年女命**顺排**；阴年男命、阳年女命**逆排**。

从出生时刻数到下一个（逆排则上一个）节气，按**精确到分钟**的口径折算：

```
1 年 = 4320 分钟      1 月 = 360 分钟      1 天 = 12 分钟
```

即「三天折一年」的细粒度版本——实际出生时刻与节气交接时刻相差多少分钟，就按上述比例折算成岁、月、日。

> **与传统时辰法的差别**：另有通行算法按「1 时辰 = 10 天」折算，粒度只有一个时辰（2 小时），出生时刻稍差一点，起运日就会跳 10 天。本站不用这一套，误差可控制在当天以内。

**起运建议配合真太阳时使用**：折算用的是出生时刻到节气时刻的真实分钟差，若填的是钟表时间而未经经度校正，东西部地区可差出十几分钟乃至一小时。勾选「启用真太阳时修正」并选好出生地，结果才可与其他排盘软件对照。

大运从起运之年起，每步十年。本版一次性排童限 + 10 步大运，覆盖到虚岁 98 以上，保证晚年的大运与流年也能逐年展开。

### 2.6 真太阳时

```
真太阳时 = 钟表时间 + (出生地经度 − 120) × 4 分钟 + 均时差
```

均时差用 NOAA 近似公式（一年内约在 −14 ~ +16 分钟之间波动），并处理真太阳时跨日的情况。

经度取自内置的 484 个市/区表，精度到地级市，够用。

### 2.7 夏令时

1935–1991 年间中国部分地区实行过夏令时，1986–1991 年为全国统一。
**只提示不自动修正**：如果你填的是当年钟表读数，需要在高级选项里手动勾选「减 1 小时」，避免重复修正。

### 2.8 运年评估（第二批）

解读部分的每一个判断都由同一条算式推出来，不掺通用话术。

**核心思路**：把大运或流年的干支当作**一柱加进命局**，看它让用神变强还是变弱。

```
天干并入权重：大运 1.0 / 流年 0.6
地支并入权重：大运 2.0 / 流年 1.2（再按藏干比例分摊）
并入后的五行力量 × 该五行的角色系数求和，再按命局五行总量归一
角色系数：用神 +1.0 / 喜神 +0.55 / 忌神 −1.0 / 仇神 −0.5 / 闲神 0
```

评分归一只除以**命局五行总量**，不除以本年增量——否则一个流年（增量小）也能打满，与十年大运同分，看不出分量差别。

**六维**：事业 / 财帛 / 感情 / 健康 / 学业 / 人际。每一维按五个来源加权：

```
五行占比 0.55 + 刑冲合害 0.30 + 宫位 0.10 + 中和度 0.05 （神煞另记）
```

| 分数 | 档位 | 文案要求 |
|---|---|---|
| ≥ 55 | 顺（good） | 说明可借力的方向 |
| 15 ~ 55 | 平（steady） | **必须**明说「此阶段此维度平稳，无重大转折」 |
| ≤ 15 | 慎（tense） | 必须附至少一条可操作建议 |

界面统一折成 0–100 的百分制（50 为中线）展示，算法内部仍以 0 为中轴。

**几点刻意的取舍**：

- 大运的年龄相关性按**十年中点**判。7~17 岁这一步若只看起运当年，会把整步运的成年维度全判成「不相关」
- 从格 / 专旺盘的分值整体收敛六成，并在报告开头并列两种取用神的口径，只作倾向提示
- 神煞（天乙、文昌、驿马、桃花等 14 项）只作辅助信号，不给分值，不单独下结论
- **全程不用 `Math.random`**：措辞变体用 FNV-1a 哈希 + 稳定种子选取，同一输入两次生成逐字相同（有对拍用例守着）

**逐年**：每年取最显著的一个维度起头；六维全落平稳时，输出固定的「无重大转折」类句子，不硬编意义。

```
wentian/
├── index.html              页面骨架
├── css/
│   ├── theme.css           配色变量、背景装饰、表单控件

│   └── echarts.min.js      ECharts 5.6.0（本地内置）
├── js/
│   ├── core/               算法层（不碰 DOM，只吐 JSON）
│   │   ├── tables.js       天干地支、藏干权重、十神、合冲刑害表

│   │   ├── wangshuai.js    旺衰量化 + 用神判定
│   │   ├── shensha.js      神煞查表（14 项）
│   │   ├── paipan.js       排盘引擎
│   │   └── assess.js       运年评估：六维评分、关系信号、关键点筛选
│   ├── text/               文案层（只拼话，不碰 DOM）
│   │   ├── phrases.js      措辞库 + 确定性选句（哈希，不用随机）
│   │   └── report.js       报告组装，输出结构化 JSON
│   ├── ui/                 渲染层（只碰 DOM，只吃 JSON）
│   │   ├── storage.js      本地档案读写
│   │   ├── charts.js       ECharts 四张图（含六维雷达）
│   │   ├── render.js       四柱表、用神框、起运、大运卡片

│   │   └── export.js       打印 / 存 PDF
│   └── app.js              表单编排、事件绑定、弹层
├── tools/
│   └── selftest.js         Node 对拍脚本（不参与页面加载）
└── README.md
```

脚本按顺序用 `<script>` 引入，无构建、无模块化，所以直接用 `file://` 打开也不会有 CORS 问题。

## 四、对拍自测

算法层改过之后，跑一遍回归：

```bash
node tools/selftest.js
```

共 17 个用例、63 项断言，覆盖：

- 1893-12-26 08:00 男 → `癸巳 甲子 丁酉 甲辰`（与通行资料对照）
- 1990-01-15 12:00 女 → `己巳 丁丑 庚辰 壬午`，起运 6 岁 7 月 21 天，首运 `戊寅`
- 2002-01-28 07:30 男 → `辛巳 辛丑 丙申 壬辰`，阴年男命逆排；真太阳时（南昌）下起运 7 岁 5 月 21 天
- 农历闰二月换算
- 不存在的闰月必须报错，不许静默滚动到相邻日期
- 立春分界（1990-02-03 → 己巳年 / 02-04 → 庚午年）
- 早/晚子时两种口径
- 乌鲁木齐真太阳时修正落在巳时
- 用 / 喜 / 忌 / 仇 / 闲 五类互斥
- 同一输入两次输出完全一致
- 神煞：桃花、华盖、天乙贵人的落柱与说明齐全，等级只有吉 / 中 / 留意三档
- 大运：童限 + 10 步，末步覆盖到虚岁 95 以上
- 报告确定性：同一输入两次生成的报告 JSON 逐字相同，且不含 `undefined`
- 信号可追溯：所有非平稳的判断都带推导依据（依据为空即失败）
- 从格判定：2002-01-28 盘判为「从弱」并附两说说明，其余用例不被误标

全部通过时输出 `算法层对拍全部通过 ✅`。

## 五、已知边界

| 情况 | 处理 |
|---|---|
| 时辰不详 | 按 12:00 估算，时柱标「时辰未详」，请自行斟酌时柱结论 |
| 出生地在境外 | 经度表只到国内地级市；可改用其他方式，或关闭真太阳时 |
| 农历 1900 年之前 / 2100 年之后 | 不支持 |
| 真太阳时、夏令时同时启用 | 先减夏令时 1 小时，再做真太阳时修正 |
| localStorage 被禁用（隐私模式） | 存档会失败并提示，排盘功能不受影响 |
